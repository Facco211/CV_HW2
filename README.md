# Transfer learning on Oxford-IIIT Pet with MobileNetV3-Small

Classification of the 37 breeds of the Oxford-IIIT Pet dataset with a MobileNetV3-Small pre-trained on ImageNet
(`MobileNet_V3_Small_Weights.DEFAULT`), comparing three strategies:

1. **Full fine-tuning**: all layers are trained.
2. **Head training**: the backbone (`features`) is frozen; `classifier[0]` and the new `classifier[3]` are trained (628,773 parameters).
3. **Frozen features + Random Forest**: 576-d features extracted after the pooling layer, classified with a scikit-learn Random Forest.

## Environment

- Python 3.12
- PyTorch 2.15.0, torchvision 0.29.2, scikit-learn 1.9.1, NumPy 2.5.4, matplotlib 3.11.2
- Hardware used for the reported results: NVIDIA GeForce RTX 5070 Ti Laptop GPU

## Setup

```
python3 -m venv venv
source venv/bin/activate          
pip install -r requirements.txt
```

The results were obtained with the CUDA 13.2 build of PyTorch. On a machine with a different CUDA version, install PyTorch following https://pytorch.org and then the remaining requirements.

## Dataset

Oxford-IIIT Pet Dataset (Parkhi, Vedaldi, Zisserman, Jawahar): https://www.robots.ox.ac.uk/~vgg/data/pets/
License: Creative Commons Attribution-ShareAlike 4.0 International (https://creativecommons.org/licenses/by-sa/4.0/); the copyright of the images remains with the original owners.

The dataset is downloaded automatically by torchvision into `./data` the first time the script runs.
The official partitions are used: `trainval` (3680 images) and `test` (3669 images).
`trainval` is split with a stratified 80/20 split (seed 42) into train (2944) and validation (736); the indices are saved in `splits/`.
Preprocessing: `weights.transforms()` for validation and test (resize 256, center crop 224, ImageNet normalisation); RandomResizedCrop(224) and RandomHorizontalFlip, followed by the same normalisation, on the training set only.

## How to run

```
python3 script.py
```

A single command runs the complete pipeline: the three approaches, the metrics, the plots and the tables.
Learning rate and best epoch of the networks and the hyperparameters of the Random Forest are selected on the validation set; the test set is evaluated once per selected model.
